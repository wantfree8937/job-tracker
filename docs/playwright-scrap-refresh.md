# 작업: 스크랩 → 내 공고 탭 자동 반영 검증

환경: 프론트 http://localhost:5173, 백엔드 http://localhost:8080

## 순서
1. http://localhost:5173 접속 → userB@test.com / password123 로그인
2. "전체 공고" 탭 클릭 → "내 관심 공고" 토글 클릭 (백엔드 공고 목록)
3. 스크랩 안 된 공고 카드 하나 찾아 "스크랩" 클릭 → "내 공고로 가져왔어요" 메시지 확인
4. (새로고침 금지!) "내 공고" 탭 클릭
5. 방금 스크랩한 공고(회사명/포지션)가 목록에 보이는지 확인 → 새로고침 없이 반영되는지가 핵심!
6. 결과 보고: 스크랩한 공고가 내 공고 목록에 즉시 보이는지 (보이면 성공)

## 주의
- 뷰포트 1280x800, 페이지 새로고침(F5) 절대 금지
- 서버/코드 수정 금지
