# 작업: UX 4종 최종 검증

환경: 프론트 http://localhost:5173, 백엔드 http://localhost:8080 (scrapedByMe 포함 새 코드)

## 검증 항목 4가지 (모두 확인!)

### 1. 새로고침 후에도 "스크랩 완료" 유지
- userB@test.com / password123 로그인
- "전체 공고" 탭 → "내 관심 공고" 토글
- 기존에 스크랩했던 공고(㈜라임컴퍼니 등)의 버튼이 **"✓ 스크랩 완료" 상태로 보이는지** 확인
- **F5 새로고침** → 그래도 "✓ 스크랩 완료" 유지되는지 확인 (핵심!)

### 2. 메시지 3초 후 자동 사라짐
- 전체 공고 탭에서 아무 공고 "스크랩" → "내 공고로 가져왔어요" 메시지 표시
- **3초 대기 후 메시지가 사라졌는지** 확인

### 3. 삭제 확인 커스텀 모달
- "내 공고" 탭 → 공고 삭제(휴지통/삭제 버튼) 클릭
- 브라우저 기본 confirm이 아니라 **화면 중앙의 커스텀 모달**이 뜨는지 확인 (취소/삭제 버튼)
- [취소] 클릭 → 모달 닫힘 확인 (삭제 안 됨)

### 4. 카드 레이아웃 균일
- 전체 공고 탭에서 카드들의 **URL과 스크랩 버튼이 모두 하단에 정렬**되어 있는지
- 내용이 짧은 카드와 긴 카드의 버튼 위치가 같은지 확인
