## 검증 1: 새로고침 후에도 "스크랩 완료" 유지 (가장 중요!)
1. userB@test.com / password123 로그인
2. "전체 공고" 탭 → "내 관심 공고" 토글 클릭
3. 아무 공고나 "스크랩" 클릭 → "✓ 스크랩 완료"로 바뀌는지 확인
4. **F5 새로고침** → "내 관심 공고" 토글 다시 클릭
5. 방금 스크랩한 공고가 **여전히 "✓ 스크랩 완료" 상태인지** 확인 ← 핵심!
